# Chapter Clarity

A free, client-side chapter readability checker.

## Features
- Flesch Reading Ease score (0–100)
- Approximate Flesch–Kincaid grade level
- Five sentences ranked by a transparent heuristic
- Highlights the five selected sentences in the full chapter
- No sign-up, API key, backend, or text upload; processing happens in the browser

## Run locally
Open `index.html` in a browser.

## Publish for free
Create a GitHub repository, upload `index.html`, then enable GitHub Pages in Settings → Pages → Deploy from a branch → `main` → `/root`. The published URL will be shown by GitHub Pages.

## Limitations
Syllable counting and sentence complexity are approximate. A long sentence is not necessarily bad, and the tool does not understand literary intent or context.
